# TV Box

A simple, mouse-friendly TV interface for Linux.

Built for an old laptop connected to a TV.
Made to browse and play a local collection of shows and movies.

## Features

- 📺 TV show library
- 🎬 Movie library
- 🎲 Random episode
- 🔥 Looping fireplace
- 🖼️ Show-specific backgrounds
- 🖱️ Mouse-friendly interface
- 🔢 Automatic season sorting
- 🎧 Per-show audio settings
